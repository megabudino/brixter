# @brixter/brix-builder

Visual page builder for Brixter: Svelte components, definitions, and editor UI consumed by the `brixter` dashboard.

## Install

Installed automatically with [`brixter`](../brixter). To use the builder on its own:

```sh
npm install @brixter/brix-builder
```

Peer dependency: Svelte 5.

## Build

Published tarballs ship compiled output from `dist/`:

```sh
npm run build
```
